A userscript that colorizes AtCoder submission rows based on their judging status.

## Usage

### Installation

1. Install any userscript manager
2. Click `atcoder-submissions-row-colorizer.user.js` in the `Assets` section of the [latest release](https://github.com/KOTO28/atcoder-submissions-row-colorizer/releases/latest)
3. Follow the instructions from your userscript manager to install

### How to Use

1. Open any AtCoder contest page and navigate to the "Results" tab
2. The submission table will be colorized based on the judging status

## Notes

- Tested and confirmed working with Firefox + Violentmonkey and Google Chrome + Tampermonkey
- The script may stop working if AtCoder changes its page structure
