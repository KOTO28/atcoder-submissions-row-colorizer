AtCoderの提出結果の行にジャッジのステータスに応じた色を付けるユーザースクリプト

## 使い方

### インストール

1. 任意のユーザースクリプトマネージャーをインストール
2. [最新のリリース](https://github.com/KOTO28/atcoder-submissions-row-colorizer/releases/latest)の `Assets` にある `atcoder-submissions-row-colorizer.user.js` をクリック
3. ユーザースクリプトマネージャーの指示に従ってインストール

### 使用方法

1. AtCoderの任意のコンテストページを開き、提出結果タブに移動
2. 提出結果の表にステータスに応じた色が付きます

## 注意事項

- Firefox + Violentmonkey および Google Chrome + Tampermonkey での動作を確認しています。
- AtCoderのページ構造が変更された場合、スクリプトが正常に動作しなくなる可能性があります。
